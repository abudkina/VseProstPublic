## Требования пользователя

1. **Брейкпоинты:** Все размеры экранов (<480px, 480-767px, 768-991px)
2. **Тип меню:** Гамбургер-меню (выдвижное боковое меню с кнопкой ☰)
3. **Особое внимание:** Верхнее меню (header)

## Технические детали

### Брейкпоинты (консистентные для всего проекта):
```css
/* Extra Small Devices (phones, <480px) */
@media (max-width: 479px) { }

/* Small Devices (phones, 480px-767px) */
@media (min-width: 480px) and (max-width: 767px) { }

/* Medium Devices (tablets, 768px-991px) */
@media (min-width: 768px) and (max-width: 991px) { }

/* Large Devices (desktops, 992px-1199px) */
@media (min-width: 992px) and (max-width: 1199px) { }

/* Extra Large Devices (large desktops, 1200px+) */
@media (min-width: 1200px) { }
```

### Гамбургер-меню структура:
```html
<!-- Кнопка гамбургера (только на мобильных) -->
<button class="hamburger-btn" id="hamburgerBtn" aria-label="Меню">
    <span></span>
    <span></span>
    <span></span>
</button>

<!-- Выдвижное меню -->
<div class="mobile-drawer" id="mobileDrawer">
    <div class="drawer-header">
        <img src="/assets/images/logo1-Photoroom1.png" alt="Всё Прост" class="drawer-logo" />
        <button class="drawer-close" id="drawerClose">&times;</button>
    </div>
    <nav class="drawer-nav">
        <a href="/" class="drawer-item"><i class="fas fa-question-circle"></i> Вопросы</a>
        <a href="/html/solutions.html" class="drawer-item"><i class="fas fa-lightbulb"></i> Решения</a>
        <!-- остальные пункты -->
    </nav>
</div>

<!-- Оверлей -->
<div class="drawer-overlay" id="drawerOverlay"></div>
```

### Основные принципы мобильной адаптации:
1. **Mobile-first подход**: базовые стили для мобильных, затем расширение для десктопа
2. **Тач-френдли элементы**: минимальный размер кнопок 44x44px
3. **Читаемость**: размер шрифта не менее 16px для основного текста
4. **Оптимизация изображений**: адаптивные изображения с srcset
5. **Производительность**: минимизация перерисовок, использование CSS transform
6. **Доступность**: сохранение всех aria-атрибутов, фокус-индикаторов
