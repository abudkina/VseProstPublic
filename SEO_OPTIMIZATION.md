## Что нужно добавить вручную

### Favicon и иконки
Для полной SEO оптимизации необходимо добавить следующие файлы в папку `/assets`:

1. **favicon.png** (или favicon.ico) - 32x32 или 16x16 пикселей
2. **apple-touch-icon.png** - 180x180 пикселей для iOS устройств
3. **og-image.png** - 1200x630 пикселей для Open Graph (социальные сети)

Эти файлы уже указаны в HTML, но их нужно создать и добавить в проект.

После развертывания проверьте:

1. **Google Search Console**: https://search.google.com/search-console
   - Добавьте сайт
   - Отправьте sitemap.xml
   - Проверьте индексацию страниц

2. **Яндекс.Вебмастер**: https://webmaster.yandex.ru
   - Добавьте сайт
   - Отправьте sitemap.xml
   - Проверьте индексацию страниц

3. **Инструменты проверки**:
   - Google Rich Results Test: https://search.google.com/test/rich-results
   - Facebook Sharing Debugger: https://developers.facebook.com/tools/debug/
   - Twitter Card Validator: https://cards-dev.twitter.com/validator

## Технические детали

### Sitemap
Sitemap доступен по адресу: `/sitemap.xml`
- Автоматически генерируется из базы данных
- Включает все проблемы и решения
- Обновляется при каждом запросе

### Robots.txt
Файл доступен по адресу: `/robots.txt`
- Разрешает индексацию всех публичных страниц
- Запрещает индексацию API и админ-панели
- Указывает путь к sitemap

### Динамические мета-теги
Для страниц проблем и решений мета-теги обновляются динамически через:
- `js/utils/seo.js` - утилиты для SEO
- `js/problem.js` - обновление мета-тегов для проблем
- `js/solution.js` - обновление мета-тегов для решений

## Конфигурация

Для правильной работы sitemap необходимо установить переменную окружения:
```env
FRONTEND_URL=https://yourdomain.com
```

Если переменная не установлена, будет использоваться значение по умолчанию из конфигурации.
