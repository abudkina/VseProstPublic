# VseProst — Платформа для обмена проблемами и решениями

## О приложении

**VseProst** — это полнофункциональная веб-платформа для обмена реальным опытом, советами и полезными покупками. Платформа объединяет людей, которые сталкиваются с различными проблемами, и тех, кто готов поделиться проверенными решениями на основе собственного опыта.

**Ключевая концепция:** Это не маркетплейс и не рекламная платформа. Пользователи делятся реальным опытом использования продуктов, услуг и решений без конкретных рекламных ссылок. Цель — создать сообщество, где люди помогают друг другу, делясь проверенными на практике советами и рекомендациями полезных покупок.

## Основные возможности

## Технологический стек

### Backend

- **Python 3.x** — основной язык разработки
- **Flask 2.3.3** — веб-фреймворк
- **Flask-SQLAlchemy 3.0.5** — ORM для работы с базой данных
- **PyJWT 2.8.0** — аутентификация через JWT токены
- **Flask-CORS 4.0.0** — поддержка CORS для API
- **PyMySQL 1.1.0** — драйвер для MySQL
- **mysqlclient 2.2.0** — альтернативный драйвер MySQL
- **Werkzeug 2.3.7** — утилиты безопасности (хеширование паролей)
- **requests 2.31.0** — HTTP клиент для внешних API
- **python-dotenv 1.0.0** — управление переменными окружения
- **bcrypt 4.1.2** — дополнительное хеширование паролей

### Machine Learning (ML/LMM)

- **sentence-transformers** — библиотека для векторизации текстов (бесплатная, open-source)
- **paraphrase-multilingual-MiniLM-L12-v2** — модель для семантического поиска и рекомендаций (поддерживает русский язык)
- **numpy** — работа с векторами и вычислениями
- **Косинусное сходство** — алгоритм поиска похожих элементов

### База данных

- **MySQL** — реляционная база данных
- **SQLAlchemy** — ORM с поддержкой сложных связей (many-to-many, one-to-many)
- **18 моделей данных** — комплексная структура данных

### Frontend

- **HTML5/CSS3** — структура и стилизация
- **JavaScript (ES6+)** — клиентская логика
- **Tom Select 2.3.1** — компоненты выбора с множественным выбором
- **Адаптивный дизайн** — поддержка мобильных устройств

### Интеграции и внешние сервисы

- **Yandex Object Storage** — хранение изображений и файлов (S3-совместимый API)
- **Yandex Search API** — поиск изображений через Yandex.Картинки
- **OpenAI API** — генерация изображений через GPT-Image
- **Placeholder сервисы** — резервные источники изображений

### Тестирование

- **pytest 7.4.3** — фреймворк для тестирования
- **pytest-flask 1.3.0** — интеграция с Flask
- **pytest-cov 4.1.0** — анализ покрытия кода
- **pytest-mock 3.12.0** — мокирование зависимостей

## Система рекомендаций на основе ML/LMM

### Технологии

- **sentence-transformers** — бесплатная open-source библиотека для векторизации текстов
- **paraphrase-multilingual-MiniLM-L12-v2** — модель из Hugging Face, поддерживающая русский язык
- **Косинусное сходство** — алгоритм поиска похожих элементов

### Как это работает

1. **Отслеживание активности** — система автоматически отслеживает действия пользователя:
   - Создание проблем и решений
   - Поисковые запросы
   - Добавление в избранное
   - Просмотры контента

2. **Векторизация** — при создании проблемы/решения автоматически создается векторное представление текста (название + описание + хэштеги)

3. **Рекомендации** — на страницах проблем и решений показываются похожие элементы в начале списка (если пользователь авторизован и нет активных фильтров)

4. **Персонализация** — рекомендации основаны на:
   - Похожести на просмотренные/созданные/добавленные в избранное элементы
   - Поисковых запросах пользователя за последние 30 дней

### Преимущества

- ✅ **Полностью бесплатно** — используются только open-source модели
- ✅ **Работает локально** — не требует платных API
- ✅ **Автоматически** — векторы создаются при создании контента
- ✅ **Персонализация** — рекомендации адаптируются под каждого пользователя
- ✅ **Поддержка русского языка** — модель поддерживает более 50 языков
